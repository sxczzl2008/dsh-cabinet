# dsh-cabinet — DeepSeek Harness 多模型内阁协作插件（测试预览版）

**`dsh-cabinet`（内阁模式）** 是一个面向 **DeepSeek Harness (DSH)** 的纯外置多模型协作插件（不修改官方 `app.asar`）。  
当前 `v0.9.0` 为**公开测试预览版（Demo）**，核心工作流与主要交互已经跑通，欢迎下载试用和反馈问题。

它把普通对话里“单次只能用一个模型回答”的方式，扩展成可按需切入的多模型分工团队：用鼠标把已配置的本地或云端模型拖入 **设计席、施工席、审验席、秘书席**，发出任务后由插件自动推进 `设计 → 设计审验 → 施工 → 施工审验 → 秘书汇总交付` 的完整流程。

## 一、 主要功能

| 功能模块 | 说明 |
| --- | --- |
| **直接复用已有模型** | 自动读取你在 DSH「设置 → 模型」里已经配好的本地和云端模型，不需要重复填写密钥或接口地址。 |
| **五大预设模式 + 独立模板** | 内置 **极简模式**（推荐日常使用：1 名施工席 + 必配秘书主脑包揽设计与验收）、**经典模式**（单击 3 席，再次双击 9 席）、**头脑风暴**（4 设计 + 4 一对一盲审 + 秘书点评汇总）、**六国大封相**（4 设计 + 4 双审 + 1 施工 + 秘书合稿施工蓝图）和 **自由模式**。每种模式都可以单独存一份模板，切换模式或新开对话时自动套用。 |
| **单模型 ↔ 内阁双向互通** | 主输入框底部只保留一个「单模型 · 切内阁 ⚙」药丸入口。切入内阁时自动承接当前对话前文；本轮交付完成后默认切回单模型并把汇报和施工实证交接给单模型继续聊；需要连续多轮用内阁推进时，勾上「持续以内阁模式工作」即可。 |
| **席位细调与工具围栏** | 支持按席位调节思考档位（`默认 / low / medium / high / max`）、输出篇幅（`精简 / 适中 / 详尽`）、审验范围翻转（`双审 / 设计审验 / 施工审验`）以及多施工席并行/顺序切换。设计席和审验席限制为只读加只读 Shell 权限，多施工席按路径白名单隔离，施工审验直接查工作区真实的 `git status / git diff` 实证。 |
| **容错跳过与熔断介入** | 多席并行时个别模型接口报错会自动标红跳过，由其余健康席位继续推进；复用子会话遇到网络中断会自动结算退出不死等。施工返工与外层大循环各自按 3 次计数，超限后触发熔断弹窗，可直接打开对应席位子对话排障或补充指令续跑。 |
| **原地分支、剪枝与正式输出** | 历史消息气泡右下角支持原地编辑开新分支（`◀ X / Y ▶` 切换）与原地剪枝/还原；内阁最终汇报以独立的正式输出区配合 GFM Markdown 渲染显示，不混入单模型折叠过程栏；右侧内阁面板顶栏支持先预览再清理已脱离工作区的幽灵对话。 |
| **经验记忆与动态扩展槽** | 岗位公共经验与模型个人记忆分开存放；工作席和秘书席预留了动态外置扩展槽，装了兼容的外置插件（如工作手册）时会自动出现按席位挂载的选项（默认未挂载），没装时不占界面空间。 |

## 二、 快速上手

### 1. 配置全局默认方案与各模式模板
打开 DSH 左下角 **「设置」** → 左侧栏点 **「内阁模式」**：
- 可以查看简明使用指引，并用鼠标拖拽排好常用的模型与席位组合。
- 点 **「保存全局默认方案」** 存为母本；在预设模式栏也可以针对不同模式点 **「存为本模式模板」** 分别保存。

### 2. 在对话里切入和退出内阁
1. 在任意对话主输入框底部，点 **「单模型 · 切内阁」** 药丸的左半区即可沿用上次或默认排席切入内阁，点右侧 **`⚙`** 打开当前对话的排席画布（可针对单次任务微调，不影响母本，也可随时回写为母本）。
2. 在主对话输入任务并发送，内阁开始按阶段推进，右侧同步展开「内阁进度」面板，点击任意成员可进入其独立子会话查看详细过程。
3. 本轮交付完成后，正式汇报会直接显示在主对话独立输出区，同时默认切回单模型直通状态；后续可继续用单模型追问，或随时再次点左下角药丸切回内阁。

## 三、 安装、卸载与版本回滚

要求：`DeepSeek Harness >= 0.2.0`、`Node.js >= 22`。  
脚本会自动查找 `DSH_HOME`（默认 `~/.dsh`）和 DSH 安装目录，也可以通过环境变量 `$env:DSH_HOME`、`$env:DSH_APP_DIR` 指定：

```powershell
# 1. 查看当前仓库状态与已有版本标签
pwsh -File "<plugin-dir>/scripts/Manage-Cabinet-Plugin.ps1" -Action Status

# 2. 安装或更新插件到本机 DSH（纯外置挂载，不改动 app.asar）
pwsh -File "<plugin-dir>/scripts/Manage-Cabinet-Plugin.ps1" -Action Install

# 或者直接运行节点同步脚本（需先退出 DSH）
node "<plugin-dir>/scripts/patch-host.cjs" --install

# 3. 回滚到指定历史版本标签
pwsh -File "<plugin-dir>/scripts/Manage-Cabinet-Plugin.ps1" -Action Rollback -Version "v0.9.0"

# 4. 卸载插件
pwsh -File "<plugin-dir>/scripts/Manage-Cabinet-Plugin.ps1" -Action Uninstall
```

```text

├── package.json                  # 插件包声明与元信息
├── cordis.patch.yml              # 宿主服务挂载配置
├── README.md                     # 使用说明
├── CHANGELOG.md                  # 版本更新记录
├── lib/
│   ├── index.js / index.mjs      # 后端服务入口、母本与模式快照存储、HTTP/SSE 路由
│   ├── client.js                 # 前端设置页、排席画布、进度看板、Markdown 输出与分支交互
│   ├── team-runtime.mjs          # 对接 DSH 原生 subagents / agentTeams / systemPrompt 底座
│   ├── orchestrator.mjs          # 内阁阶段编排、盲写盲审、工具围栏与熔断控制
│   ├── branch-tree.mjs           # 多帧 Zstd 物理分支与主从级联生命周期管理
│   ├── context-surgery.mjs       # 上下文原地剪枝与原文还原
│   ├── model-catalog.mjs         # 读取 DSH 已配置的本地/云端模型目录与思考档位
│   └── memory-router.mjs         # 岗位经验、模型记忆与外置扩展动态桥接
└── scripts/
    ├── Manage-Cabinet-Plugin.ps1 # 安装、回滚与卸载脚本
    └── patch-host.cjs            # 纯外置 bundle 宿主同步脚本
```
