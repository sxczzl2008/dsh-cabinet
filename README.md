# dsh-cabinet — DeepSeek Harness 多模型内阁协作工作流插件

**`dsh-cabinet`（内阁模式）** 是专为 **DeepSeek Harness (DSH)** 打造的多模型分工协作与可视化编排插件。  
它将原本“单一对话只能由单一模型应答”的交互方式，扩展为**由多个本地或云端 AI 模型组成内阁团队**，通过纯鼠标气泡拖拽分配 **设计席、施工席、审验席** 与 **秘书席**，在发出任务后由插件代码自动驱动 `设计 → 设计审验 → 施工 → 施工审验 → 交付主对话 + 秘书简报` 全流程闭环。

---

## 一、 主要功能

| 功能模块 | 说明 |
| --- | --- |
| **直接用已有模型** | 直接读取你在 DSH「设置 → 模型」里已经配好的本地和云端模型，不用再填一遍 API 密钥或接口地址。 |
| **五大预设模式一键排座** | 内置 **经典模式**（单击加载 1+1+1 三席，再次双击扩展加载 3+3+3 九席）、**极简模式**（2 席：1 施工 + 1 设计兼施工审验）、**头脑风暴**（8 席 + 必配秘书席：4 设计 + 4 一对一盲审，不打回重做，由秘书汇总点评）、**六国大封相**（9 席 + 必配秘书席：4 设计 + 4 双审 + 1 施工，由秘书兼任合稿唯一《施工蓝图》）和 **自由模式**。 |
| **思考档位拉杆与右侧齿轮翻转标签** | 待放区模型气泡、工作席与秘书席均内置思考档位拉杆（`默认 / low / medium / high / max`）；审验席卡片右侧边缘悬挂纵向齿轮标签（点击在 `双审 ⇄ 设计审验 ⇄ 施工审验` 三态翻转），3 席及以上施工组右侧标签支持全组联动在 `并行施工 ⇄ 顺序施工` 间翻转（1 席施工固定为 `单席直施`，2 席施工自动禁用并提示需 1 席或 3 席以上）。 |
| **平行盲写、一对一盲审与实证围栏** | 设计组员零开场干扰并行盲写；审验组支持一对一匿名盲审并按纯代码**一票否决**判定；多设计席进施工前由设计组长（经典 9 席）或秘书席（六国大封相）合稿唯一《施工蓝图》；分片施工按路径白名单硬隔离，施工审验吃工作区真实 `git status / git diff` 实证包并拥有全仓只读与只读验证 Shell 权限。 |
| **双层独立退回计数与三次熔断弹窗** | 施工审验发现笔误小错先退回施工席局部返工（最多 3 次，独立计数），3 次无效返工后自动升级退回设计组重新出具方案；整体大循环满 3 轮仍未通过时立即触发强制熔断并弹出人工介入排障窗口，支持一键打开设计/施工/审验组子会话排障或补充指令续跑。 |
| **岗位经验与模型记忆分开存** | 按 `设计 / 施工 / 审验 / 秘书` 四个岗位存公共经验，按模型型号存各自的习惯记录；换别的模型来当秘书或干活时能直接接着用岗位经验，不同模型自己的记忆也不会混在一起。 |

## 二、 快速上手指南

### 1. 在设置页查看指引与配置全局母本
打开 DSH 左下角 **「设置」** → 在左侧导航栏点击 **「内阁模式」**（位于「桌面控制」下方）：
- **使用指引卡**：随时查阅启动方式、气泡操作与三色状态栏说明。
- **全局默认方案（母本）**：在此预先排好你日常最常用的模型与职责组合，点击 **「保存全局默认方案」**。空白秘书席为可选职位，不绑定模型亦可正常运行。

### 2. 在具体对话中启动内阁模式（子代配置）
1. 在任意聊天对话输入框**右下角的模型选择下拉菜单**底部，点击 **「内阁模式」**。
2. 弹出宽幅「本对话配置（子代）」窗口（新对话会自动带入你的全局默认母本）。
3. 可针对当前任务自由增减工作席（1～9 席）、更换模型或调整组长/组员：
   - 点击 **「应用到本任务」**：仅在当前对话生效，不改变全局母本；
   - 点击左下角 **「一键设为默认配置」**：将当前对话的排席直接覆盖保存为全局母本；
   - 点击 **「载入全局默认」**：从全局母本重新拉取排席。
4. 在主对话输入框输入任务按回车，内阁即刻开始自动推进，右侧同步展开窄版状态栏。

## 三、 安装、卸载与版本回滚

脚本会自动查找当前系统的 `DSH_HOME` 和 DSH 安装目录（也可以用环境变量 `$env:DSH_HOME`、`$env:DSH_APP_DIR` 指定）：

```powershell
# 1. 查看当前仓库状态与已有版本标签
pwsh -File "<plugin-dir>/scripts/Manage-Cabinet-Plugin.ps1" -Action Status

# 2. 安装或更新插件到本机 DSH
pwsh -File "<plugin-dir>/scripts/Manage-Cabinet-Plugin.ps1" -Action Install

# 3. 回滚到指定的历史版本标签（如 v0.1.3）
pwsh -File "<plugin-dir>/scripts/Manage-Cabinet-Plugin.ps1" -Action Rollback -Version "v0.1.3"

# 4. 卸载插件
pwsh -File "<plugin-dir>/scripts/Manage-Cabinet-Plugin.ps1" -Action Uninstall
```

```text
    ├── Manage-Cabinet-Plugin.ps1 # 安装、回滚与卸载脚本
    └── patch-host.cjs            # 纯外置 bundle 宿主同步脚本
```
